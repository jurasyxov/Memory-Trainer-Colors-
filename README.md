🎨 Memory Trainer (Colors) — тренируй память с цветами

> «Запомни цвет, повтори последовательность»

**Memory Trainer (Colors)** — это набор консольных приложений для тренировки кратковременной памяти на запоминание последовательностей цветов.  
Программа показывает ряд цветов, которые нужно запомнить и воспроизвести в правильном порядке. С каждым уровнем сложность возрастает.

## 🚀 Особенности
- 🎨 Генерация случайных последовательностей цветов (красный, синий, зелёный, жёлтый, фиолетовый, голубой, белый).
- 📈 Уровни сложности: от 3 до 10+ цветов.
- 🎯 Подсчёт правильных ответов, очков и времени реакции.
- 🎮 Интерактивный режим с вводом названий цветов (на английском или русском).
- 🎨 Цветной вывод в терминале (ANSI) для наглядности.
- 📊 Сохранение статистики (рекорд, количество игр) в файл.
- 🔄 Возможность повтора уровня при ошибке (опционально).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `colorama` (опционально)             | `python memory_trainer.py`              |
| Go         | стандартная библиотека               | `go run memory_trainer.go`              |
| JavaScript | Node.js (без внешних модулей)        | `node memory_trainer.js`                |
| Java       | стандартная библиотека               | `javac MemoryTrainer.java && java MemoryTrainer` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `colored`, `rand` (crates)           | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby memory_trainer.rb`                |
| PHP        | стандартная библиотека               | `php memory_trainer.php`                |
